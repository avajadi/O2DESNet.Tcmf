# Releasing

The three packages (`O2DESNet.Tcmf`, `O2DESNet.Tcmf.Kafka`, `O2DESNet.Tcmf.Rest`) are released together
from a version tag. Nothing reaches nuget.org without a tag.

## One-time setup

1. Sign in to https://www.nuget.org with a Microsoft account (two-factor authentication required).
2. Create an API key under *API Keys* with scope **Push new packages and package versions** and the
   glob pattern `O2DESNet.Tcmf*`. Keys expire after at most a year; note the date.
3. In the GitHub repository, create an environment called `nuget` (*Settings → Environments*) and add the
   key as the secret `NUGET_API_KEY`. Optionally require a reviewer on that environment so a tag push
   still needs a manual approval before publishing.
4. After the first publish, add the other maintainers as package owners on nuget.org.

## Each release

1. Set the same `<Version>` in the three `src/*/*.csproj` files. Use a suffix for a preview
   (`0.2.0-preview.1`); previews are hidden from default searches on nuget.org.
2. Move the *Unreleased* entries in `CHANGELOG.md` under a new heading with the version and date, and
   update the compare links at the bottom.
3. Run `dotnet test` and `dotnet pack -c Release -o artifacts`, then open a `.nupkg` (it is a zip) and check
   the README, license and dependencies look right.
4. Commit, then tag and push:

   ```
   git tag v0.2.0
   git push origin main v0.2.0
   ```

   The *Release* workflow verifies that the tag matches every package version, builds, tests, packs and
   pushes the `.nupkg` and `.snupkg` files. Validation on nuget.org takes a few minutes.
5. Create a GitHub release from the tag with the changelog section as its notes.

## Publishing by hand

```
dotnet pack -c Release -o artifacts
dotnet nuget push 'artifacts/*.nupkg' --api-key <key> --source https://api.nuget.org/v3/index.json --skip-duplicate
```

Push the core package first if you push one at a time; the sink packages depend on it at the same version.

## Things to remember

- A published version is permanent. It can be unlisted, never deleted. When in doubt, publish a preview.
- The `O2DESNet.` ID prefix is not reserved on nuget.org; the other `O2DESNet.*` packages belong to the
  O²DES.NET maintainers at NUS. Let them know before the first publish.
- Keep the LICENSE copyright holder, `Directory.Build.props` and the package READMEs in agreement.
- The package icon is `assets/icon.png`, generated by `python3 assets/make-icon.py` (needs Pillow and
  DejaVu Sans Bold). Edit the script rather than the PNG.
